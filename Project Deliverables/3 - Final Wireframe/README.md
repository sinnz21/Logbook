# Final Wireframe

The Figma design ("figma ver2", file LogbookISU): 20 screens — sign-in, Nurse screens, Admin screens,
dialogs, and the two clinic forms. `ISU_Infirmary_Wireframe.pdf` shows them one per page; `svg/` has each screen.

Changes made after this design, now in the final system:

- **Insights** became the **Reports** group: Reports → Analytics (12 pages, one chart each),
  Reports → Tables (11 pages with CSV), and the Monthly supply report.
- **Health surveillance** was added: the outbreak banner on the Nurse dashboard and the Outbreak watch page.
- Settings gained Export .SQL, Trash and Maintenance mode; the Admin dashboard shows backup and stock status.

The final mockup (folder 4) and the evidence screenshots (folder 6) show these screens.
