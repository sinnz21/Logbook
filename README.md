# ISU Infirmary Logbook Management and Health Surveillance System

Software Engineering 1 · BSCS 3-1 · Isabela State University – Echague
Gaffud, Cyrille Jef N. (leader, backend) · Nicolas, Dj Jaziel P. (frontend)

A web system on the clinic's LAN for the University Health Service: patient visits, medicines and supplies,
stock and restock requests, reports, and an early warning when an illness is spreading in a college.
