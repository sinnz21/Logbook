================================================================================
          INFIRMARY SYSTEM - TO-DO LIST, REQUIREMENTS & ASSIGNMENTS
================================================================================

[ 1. SYSTEM ARCHITECTURE & PROTOTYPING ]
--------------------------------------------------------------------------------
* Design & Prototyping:
  - Create UI/UX wireframes/mockups in Figma first ("first Figma").

* System Architecture & Deployment:
  - Cloud-based deployment: For access anytime and anywhere.
  - LAN-based setup: Configured on a Client-Server architecture so both Admin and
    Nurse can access the application locally.


[ 2. INTERVIEW & REQUIREMENTS GATHERING (STAKEHOLDER INQUIRIES) ]
--------------------------------------------------------------------------------
* Roles & Permissions:
  - Interview staff: Who uses the stock? Who is authorized to add stock?
  - Determine who has System Admin privileges.

* Terminology & Record Fields:
  - Visit Records: Clarify the preferred general term to use (e.g., "Patients" vs. "Visitors").
  - Categorization: Include Level and Department fields.
  - Release / Referral: Determine what exact data needs to be captured when a patient/visitor
    visits or gets referred from the infirmary.
  - Patient Record Form: Check actual physical/existing forms to verify if Student Number
    is required and what specific fields are filled up.
  - Vitals / Health Data: Confirm what medical measurements are taken (e.g., Blood Pressure / BP, etc.).
  - Stocks & Supplies Form: Verify how staff currently logs/fills up stock and supply sheets.


[ 3. PATIENT & VISIT RECORDS MANAGEMENT ]
--------------------------------------------------------------------------------
* User Profile Fields:
  - First Name (F name)
  - Last Name (L name)
  - Middle Name (M name - Optional)

* Scope of Patients:
  - Add Faculty / Staff members to Visit & Patient Records (not only students).

* Year Level Progression Logic:
  - Define logic for updating student year levels over time (e.g., tracking a student who visited
    multiple times during 1st year, and now visits as a 2nd year student).

* Timestamps & Audit Logs:
  - Account / Record Created: Timestamp when created.
  - Account / Record Modified: Timestamp when modified.


[ 4. TABLE, FILTERING, SORTING & EXPORT FEATURES ]
--------------------------------------------------------------------------------
* Search, Export & Print:
  - Search bar functionality across records.
  - Export data to PDF and CSV formats.
  - Add "Customize Print" functionality for reports/records.

* Pagination:
  - Implement pagination for large datasets (e.g., 1,000+ records).
  - Page size selector (e.g., Show 50, Show 100 / Show 10 records per page).

* Column Sorting:
  - Make table headers clickable for ascending/descending sorting.

* Advanced Filtering:
  - Date search range filter (e.g., Month range: January - March, custom date ranges).
  - Multi-attribute filters: Filter by Gender, Year Level, Program, and Department.

* Search Optimization:
  - Optimize search history / queries.
  - Apply Computer Science algorithm (CS search algo) for faster, efficient search queries.


[ 5. INVENTORY, STOCKS & SUPPLIES ]
--------------------------------------------------------------------------------
* Stock Status Indicators (Legend):
  - [ OK ]       -> Normal / Sufficient stock
  - [ LOW ]      -> Reorder threshold reached
  - [ CRITICAL ] -> Near empty / Urgent restock required

* Tracking & Stock In/Out:
  - System logging for who adds stock and who dispenses/uses stock.


[ 6. DASHBOARD & INSIGHTS (ANALYTICS) ]
--------------------------------------------------------------------------------
* Insights Dropdowns:
  - Add missing dropdown selectors in Insights/Analytics.
  - Historical Data view: Enable viewing past records filtered by Year and Month.
  - Ensure charts/visuals update appropriately based on selection.

* Dashboard Quick Links & Top Metrics:
  - Quick Link / Top 5 Most Frequently Requested Medicines:
    "Gamot na madalas kunin" (Top 5 list, clickable per record).

* Alert / Notification Display:
  - Display system warnings and alerts (e.g., low stock warnings, critical thresholds).


[ 7. SYSTEM ADMINISTRATION & DATABASE MAINTENANCE ]
--------------------------------------------------------------------------------
* Soft Delete:
  - Implement soft delete across records (preserve data integrity without permanent removal).

* Backup & Recovery:
  - Automated Backup
  - Manual Backup
  - Database Recovery feature

* Database Export:
  - Functionality to export/dump the database.


[ 8. AUTHENTICATION, UI & SECURITY ]
--------------------------------------------------------------------------------
* Password Policy (UI / Forgot Password):
  - Password rules: Minimum of 8 characters, at least 1 symbol/special character, signs, etc.
  - Forgot password / reset flow.

* Rate Limiting & Brute-Force Protection:
  - Track and count failed login attempts.
  - Remedy / Action: Trigger reset link, temporary lockout / lock out the app after threshold.
